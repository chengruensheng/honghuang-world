# 门禁-府 · 质量门禁（PowerShell 辅佐层）

> 定位：洪荒的工程纪律门禁——格式 / 静态检查 / 测试 / 重复检测 / 依赖图，一键四件套。
> 落位：`道果树 / 质量门禁-域 / 门禁-府`（不入 Cargo workspace，同 `乾坤/呈现-域/监控界面-府` 先例）。
> 依据：`融合蓝图-设计稿.md` §14.8（dsh 手法对齐纲领 · 阶段 1 细化）。

## 用法

```powershell
pwsh -File 检查-全部.ps1          # 四件套全跑（fmt + clippy + test + 重复）
pwsh -File 检查-全部.ps1 -只查重复  # 只跑重复检测（快速）
pwsh -File 查重复.ps1 -阈值 0.10   # 自定义重复阈值
pwsh -File 生成依赖图.ps1 -输出 依赖图.md  # 生成府间依赖图（mermaid）
```

## 四件套

| # | 件 | 命令 | 判定 |
|---|---|---|---|
| 1 | 格式 | `cargo fmt --check` | 零差异 |
| 2 | 静态 | `cargo clippy --workspace --all-targets -- -D warnings` | 零警告 |
| 3 | 测试 | `cargo test --workspace --lib` | 零失败 |
| 4 | 重复 | `查重复.ps1` | 重复率 ≤ 阈值 |

## 重复阈值策略

阶段 1 默认 **15%**（基线 10.6%）。每阶段按重复报告消减 ≥2 个百分点，阶段 6 前收至 **5%**。

当前重复基线（2026-08-19 实测）：387 .rs 文件 / 20573 代码行 / 重复行 2180 / **10.6%**。

已知重复热点（backlog，阶段 2-3 消减）：
- 目录递归扫描逻辑（巡世扫描.rs × 增量检测.rs）
- 日期计算（流式历法.rs × 流式时刻.rs）
- 工具调用名统计（工具循环测试.rs × 工具循环.rs）
- 文件操作样板（多个 手脚-施展-殿 文件）

## 依赖图

`生成依赖图.ps1` 解析全部 .rs 的 `lib::` 路径限定引用（use 导入 + 全路径调用，过滤 std/第三方），
聚合府间依赖边，输出 mermaid。实测 28 条边，与设计稿 §8 依赖关系一致。

## 钩子

pre-commit 钩子（`.git/hooks/pre-commit`，git 强制名）跑快速烟雾：fmt + clippy。
全量测试与重复检测走 `检查-全部.ps1`（CI / 手动 / 版本存档前）。
