# 提交前验证

提交前的一键全验流程。质量唯一标尺 = `cargo test` 全绿 + `cargo clippy` 零警告（AGENTS 第 15 条）。

## 一键全验

```bash
bash 一键全验.sh
```

10 项全过才退出 0。任一项失败立即修复，不得带病提交。

## 提交规则

1. 全验通过后再提交
2. 提交信息聚焦「为什么」而非「做了什么」
3. 不提交 `.env` 凭据、密钥
4. 不提交 `.上下文/.test-tmp/` 测试残留（已 gitignore）
5. 临时产物放 `临时文件夹/`（已 gitignore），任务结束后清空
