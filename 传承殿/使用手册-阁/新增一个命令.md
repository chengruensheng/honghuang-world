# 新增一个命令

在命令分发中新增一个「域+动作」命令，供界主经 `号令` CLI 调用。

## 落点

| 文件 | 作用 |
|------|------|
| `兜底分发.rs` | 命令表 + 分发逻辑 |
| `入口.rs` | 府根模块声明（若新增阁/园） |

路径：`乾坤/呈现-域/命令操作-府/命令-解析-殿/命令-分发-阁/兜底-分发-园/兜底分发.rs`

## 步骤

### 1. 在命令表追加三元组

```rust
const 命令表: &[(&str, &str, &str)] = &[
    // …
    ("巡世", "驱动", "AI"),
    ("新域", "新动作", "读"),  // 新增
];
```

三元组含义：`(域, 动作, 权限)`，权限分 `读`（无副作用）/ `AI`（可能触发模型调用或写操作）。

### 2. 实现处理函数

在对应阁/园下编写：

```rust
pub fn 新动作(参数: &str) -> String {
    // 业务逻辑
    format!("结果：{参数}")
}
```

### 3. 在分发逻辑追加 match 分支

```rust
pub fn 分发调用(调用: &调用) -> 结果 {
    let 取参 = |索引: usize| 调用.参数.get(索引).cloned().unwrap_or_default();
    match (调用.域.as_str(), 调用.动作.as_str()) {
        // …
        ("新域", "新动作") => 成功(新动作(&取参(0))),
        (域, 动作) => 失败(format!("未知命令：{域} {动作}")),
    }
}
```

### 4. 若需新阁/园，在府根追加模块声明

```rust
#[path = "命令-解析-殿/新阁/模块.rs"] pub mod 新阁;
```

## 验证

```bash
cargo test -p mingling_fu --lib     # 府内测试
cargo run -p mingling_fu --bin 号令 -- 新域 新动作 参数  # 手动验证
```

## 约束

- 命令域/动作用中文
- `读` 权限命令不得有副作用（不写文件、不调模型）
- `AI` 权限命令可能触发模型调用或写操作
- 新命令须在 `证道/鸿蒙 - 域/单元测试-府/命令操作-验证-殿/` 下补测试
- 帮助清单自动从 `命令表` 生成，无需手维护
