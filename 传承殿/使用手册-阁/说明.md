# 使用手册阁

本阁收录「洪荒·世界」常用开发操作的实操手册（cookbook）。每篇手册聚焦一个常见任务，给出落点、步骤、示例与验证方法。

## 手册索引

| 手册 | 用途 |
|------|------|
| [新增一个道术.md](新增一个道术.md) | 在工具流水线中注册一个新工具（道术） |
| [新增一个府.md](新增一个府.md) | 在 workspace 中新建一个府（crate） |
| [新增一个命令.md](新增一个命令.md) | 在命令分发中新增一个域+动作 |
| [新增一个验证园.md](新增一个验证园.md) | 在六层结构中新增测试 |
| [排查问题.md](排查问题.md) | 排查问题的流程与原则 |
| [提交前验证.md](提交前验证.md) | 提交前的一键全验流程 |

## 阅读顺序

- 新加入者：先读「新增一个府」→「新增一个道术」→「提交前验证」
- 排查回归：先读「排查问题」→「提交前验证」
- 扩展命令面：读「新增一个命令」
