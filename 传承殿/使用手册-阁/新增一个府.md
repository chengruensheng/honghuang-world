# 新增一个府（crate）

在 workspace 中新建一个府，遵循六层结构「维度/域/府/殿/阁/园」。

## 落点

府目录创建在对应维度/域下：

```
<维度>/<域>/<府名>-府/
  ├─ Cargo.toml
  └─ 入口.rs
```

## 步骤

### 1. 建目录与 Cargo.toml

以「鸿蒙/基础设施 - 域/观测探针-府」为例：

```toml
[package]
name = "guance_fu"
version = "0.1.0"
edition = "2021"

[lib]
name = "guance_fu"
path = "入口.rs"
doctest = false

[dependencies]
rizhi_fu = { path = "../日志记录-府" }
shihai_fu = { path = "../识海承载-府" }
```

命名规则：
- 目录名：中文 `<府名>-府`
- crate 名：拼音 `_fu` 后缀
- lib 入口：`入口.rs`

### 2. 写入口.rs

最小入口：

```rust
//! 观测探针-府：五哨兵域的探针承载。

pub mod 某殿;
```

若需对外暴露服务，实现插件 trait：

```rust
pub struct 观测插件;
impl chajian_fu::府插件 for 观测插件 {
    fn 名称(&self) -> &str { "观测探针-府" }
    fn 注入(&self) -> Vec<&str> { vec!["识海承载-府"] }
    fn 应用(&self, ctx: &mut chajian_fu::插件上下文) -> Result<(), String> {
        let 服务: std::sync::Arc<dyn 某服务> = std::sync::Arc::new(服务实例);
        ctx.注册服务(服务)?;
        Ok(())
    }
}
```

### 3. 注册到 workspace

在根 `Cargo.toml` 的 `members` 追加：

```toml
members = [
    # …
    "鸿蒙/基础设施 - 域/观测探针-府",
]
```

### 4. 建测试镜像

在 `证道/鸿蒙 - 域/单元测试-府/` 下建对应验证殿：

```
证道/鸿蒙 - 域/单元测试-府/
  └─ <府名>-验证-殿/
       └─ 模块.rs
```

在 `入口.rs` 追加模块声明：

```rust
#[path = "观测探针-验证-殿/模块.rs"] pub mod 观测探针_验证_殿;
```

在 `Cargo.toml` 追加依赖：

```toml
guance_fu = { path = "../../../鸿蒙/基础设施 - 域/观测探针-府" }
```

## 验证

```bash
cargo check --workspace              # 全 workspace 编译
cargo test --workspace --lib         # 全测试
cargo clippy --workspace -- -D warnings  # 零警告
```

## 约束

- 府是唯一引用止步点：跨府只认 lib 根 pub 符号，不深链私有
- 府内依赖用相对路径（同域 `../`，跨域 `../../../`）
- 日志统一经 `rizhi_fu` lib 根调用，不自建日志
- 严禁 `src/`、`tests/`、`scripts/` 平铺目录（AGENTS 第 10 条）
- 新府须先并入设计稿对应章节再实现（AGENTS 第 8 条）
