## 三、教训（snapshot 2026-08-24 · 已固化到助理记忆「教训」格位 6 条）

详见助理记忆 `教训.jsonl` 的 6 条记录。摘要：

1. **fs 写盘需 sandboxPolicy**：插件内 `fs.writeText` 必须显式传 `{ mode: 'workspace-write', workspaceRoot }`，否则被 sandbox 拒绝。
2. **结构格位需下探园级 fn 签名**：仅扫 lib 根不够防脑补 API，要扫到园的 `pub fn` 完整签名。
3. **timeoutMs 必声明**：Cordis 插件工具 execute 必须显式 `timeoutMs`，否则无超时上限，串行 await 链路会让 Harness 实例挂起，只能进程级 kill。
4. **output 必须结构化对象，render 只做 markdown**：enum 必配 type:string、嵌套对象必显式 additionalProperties:true|false、DSH DSL 不支持 required 字段。
5. **description 必带「何时用 / 何时不调」**：纯功能描述不够，模型靠 description 判断是否触发该工具。
6. **扫描类操作三件套**：限深 + 超时 + 用户主动调。本次会话实测：项目实际 459 个 .rs，但 3 层深只能数到 19。

## 五、助理插件 gewei-1 的状态（snapshot 2026-08-24 · 仅作历史记录，**不**作为生产路径）

- 模式：动态 Cordis 插件，phase=active。
- 工具：`gewei_quick`（< 50ms 速返首因）/ `gewei_projection`（< 5s 完整投影）/ `gewei_read`（单格位读）/ `gewei_wave_start`（后台海浪式，仅作设计验证）。
- 已知风险：插件 fs 写盘受 sandboxPolicy 约束、execute 串行 await 长链路可能挂起、schema 字段误配会导致 `additionalProperties` 校验失败。
- 推荐替代：让 DSH `agent-instructions` + `session-reference` 做项目记忆与跨会话持久化，**不再依赖**此插件。
