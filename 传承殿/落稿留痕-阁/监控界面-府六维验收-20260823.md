## 三、跨府引用边界

- 跨府引用止步 lib 根：仅 `use jiankong_fu::符号`（白箱事件/影响项/token用量/事件类型/事件流路径/读事件流 等）
- 测试镜像殿在 `证道/单元测试-府`（zhengdao_fu），不内联到监控界面-府自身
- 中文模块名挂载用 ASCII 别名（`pub mod t_bxb_contract;` + `#[path = "白箱契约测试.rs"]`）—— Rust 1.97 E0754 限制
- 测试文件顶层 `#![cfg(test)]` 避免 clippy 报 unused import

## 四、运行约束

- **串行测试必跑**：本批测试涉及 `WORLD_WORKSPACE_ROOT` 环境变量，并行 cargo test 会导致 mingling_fu/天庭治理 等既有测试也撞锁失败。提交脚本固定 `cargo test --workspace --lib -- --test-threads=1`。
- **临时目录唯一化**：每个测试用 `pid + nanos` 命名临时工作区，避免串行执行间残留污染。
