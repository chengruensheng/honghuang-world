## 三、实现经验（沉淀，供后续引擎复用）

1. **首现持久化模块落地成功**：TOML 落盘 + 加载还原 + `next_id` 延续，闭环跑通。
2. **修复一处测试隔离缺陷**：设计文档初版测试用共用固定临时路径 `qk_memory_test.toml`，两个持久化测试并发执行时互相覆盖文件导致 `持久化往返` 失败。已改为 `临时路径(名)` 生成独立文件名（`往返`/`延续`），并**同步修正设计文档至 v1.1**，避免后续实现 agent 抄到同样缺陷。
3. **教训**：凡涉及落盘/文件读写的证道测试，临时文件路径必须按测试名隔离，不能共用固定路径。
4. **无回归**：新增 qk-memory/zd-memory-test 后，鸿蒙、太初、量劫及证道测试全绿。
