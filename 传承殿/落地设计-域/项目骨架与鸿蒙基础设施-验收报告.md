## 三、实现经验（供后续引擎复用）

1. **中文路径全链路可行**：`F:\洪荒 - 世界`（含域/府/殿/阁/园全中文目录）下 cargo build/test/run 全部通过，无需改英文目录名。
2. **模块汇总方案已验证**：`#[path = "殿名/模块.rs"] mod 标识符;`（连字符转下划线）+ 园内中文名直接 `mod`，编译与运行均正常。
3. **serde 默认值冲突**：`#[serde(default = "函数")]` 与 `#[derive(Default)]` 不能混用——derive 生成的默认值是空串，会与 serde 指定的默认函数语义冲突。**正确做法**：去掉 `#[derive(Default)]`，手写 `impl Default` 复用同一个默认函数（见落地设计 6.3 已同步修正）。
4. **PowerShell 误报**：`cargo ... 2>&1` 在 PowerShell 下会把 cargo 写到 stderr 的正常进度输出报红为 `NativeCommandError`，非真实错误，以 exit code 和最终输出为准。
