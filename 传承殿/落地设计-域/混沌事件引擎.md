# 混沌·事件引擎 落地设计

> **定位**：第六个落地模块（五行闭环最后一环）。兑现五行之**水**（流动、无定形）——事件是"状态变化的流动信号"。核心职责：事件发布、订阅分发、事件历史、落盘持久化。
>
> **状态**：v1.0 · 2026-09-04
>
> **上游契约**：`传承殿/已定契约-域/已定契约.md`（实现必须遵守）
>
> **组织规则**：`.codeartsdoer/rule/代码组织规则.mdc`（规模上限、模块.rs 汇总、证道只测府级）
>
> **前置**：鸿蒙、太初、量劫、乾坤、道韵均已实现并验收通过，复用其 hm-error、hm-contract、「模块汇总 + 证道测府级」范式，以及乾坤/道韵已验证的 TOML 持久化范式。

---

## 0. 设计目标

在九根之**混沌**下落地事件引擎，跑通"事件发布 → 订阅分发 → 历史记录 → 落盘 → 加载还原"的最小闭环。

验证点：
1. 混沌根下域 ≤ 3，代码只落园（无 `src`），crate 根为府级 `模块.rs`
2. 事件能发布（流动）、能按 id 查询、能列出历史（按发布顺序）
3. 订阅分发：发布某类型事件时，匹配类型的处理器被调用，不匹配的处理器不被调用
4. 事件历史能落盘（保存）并从文件还原（加载），往返内容一致，加载后 id 延续不冲突
5. 订阅关系为运行时态，不落盘（加载后需重新订阅）
6. 府可插拔：`EventBus` 实现 `Component` 契约
7. 测试全在证道，只测 hd-event 府级公共 API

## 6. crate 设计（hd-event）

### 6.1 Event 事件条目（事件定义-殿/事件模型-阁/事件-数据-园）

园内 `事件数据.rs`：

```rust
use serde::{Deserialize, Serialize};

/// 事件：水之流动，一次状态变化的记录
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Event {
    pub id: u64,
    pub 类型: String,
    /// 载荷：键值对列表，事件携带的数据（与规则引擎的事实表示一致）
    pub 载荷: Vec<(String, String)>,
    pub created_at: u64,
}

impl Event {
    pub fn 新建(id: u64, 类型: String, 载荷: Vec<(String, String)>, created_at: u64) -> Self {
        Event { id, 类型, 载荷, created_at }
    }
}

/// 当前秒级时间戳
pub fn 当前时间戳() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs()
}
```

### 6.2 EventBus 事件总线（事件分发-殿/事件总线-阁/总线-模块-园）

园内 `总线模块.rs`：

```rust
use std::sync::Arc;
use hm_contract::Component;
use hm_error::{Error, Result};
use serde::{Deserialize, Serialize};
use crate::事件定义_殿::{Event, 当前时间戳};

/// 可序列化的事件日志（EventBus 的持久化载体，订阅关系不落盘）
#[derive(Debug, Clone, Serialize, Deserialize)]
struct EventLog {
    events: Vec<Event>,
    next_id: u64,
}

/// 事件总线：水之流动，订阅分发 + 事件历史 + 落盘持久化
pub struct EventBus {
    subscribers: Vec<(String, Arc<dyn Fn(&Event) + Send + Sync>)>,
    events: Vec<Event>,
    next_id: u64,
}

impl EventBus {
    pub fn new() -> Self {
        EventBus {
            subscribers: Vec::new(),
            events: Vec::new(),
            next_id: 1,
        }
    }

    /// 订阅某类型事件（处理器闭包，运行时态不落盘）
    pub fn 订阅(&mut self, 类型: &str, 处理器: Arc<dyn Fn(&Event) + Send + Sync>) {
        self.subscribers.push((类型.to_string(), 处理器));
    }

    /// 发布事件：创建、分发给匹配类型的处理器、记录历史，返回事件 id
    pub fn 发布(&mut self, 类型: String, 载荷: Vec<(String, String)>) -> u64 {
        let id = self.next_id;
        self.next_id += 1;
        let event = Event::新建(id, 类型.clone(), 载荷, 当前时间戳());
        for (订阅类型, 处理器) in &self.subscribers {
            if 订阅类型 == &类型 {
                处理器(&event);
            }
        }
        self.events.push(event);
        id
    }

    /// 按 id 查询
    pub fn 按id(&self, id: u64) -> Option<&Event> {
        self.events.iter().find(|e| e.id == id)
    }

    /// 事件历史（按发布顺序）
    pub fn 历史(&self) -> Vec<&Event> {
        self.events.iter().collect()
    }

    /// 保存到文件（仅落盘事件历史，订阅关系不落盘）
    pub fn 保存(&self, path: &str) -> Result<()> {
        let log = EventLog {
            events: self.events.clone(),
            next_id: self.next_id,
        };
        let content = toml::to_string(&log)
            .map_err(|e| Error::Other(format!("序列化事件失败: {e}")))?;
        std::fs::write(path, content)
            .map_err(|e| Error::Other(format!("写入事件文件 {path} 失败: {e}")))?;
        Ok(())
    }

    /// 从文件加载（还原事件历史，订阅关系需重新注册）
    pub fn 加载(path: &str) -> Result<Self> {
        let content = std::fs::read_to_string(path)
            .map_err(|e| Error::Other(format!("读取事件文件 {path} 失败: {e}")))?;
        let log: EventLog = toml::from_str(&content)
            .map_err(|e| Error::Other(format!("解析事件文件失败: {e}")))?;
        Ok(EventBus {
            subscribers: Vec::new(),
            events: log.events,
            next_id: log.next_id,
        })
    }
}

impl Component for EventBus {
    fn name(&self) -> &'static str { "事件总线" }
}
```

依赖：`hm-error`、`hm-contract`、`serde`、`toml`。

> 说明：`EventBus` 含闭包字段（订阅关系），不能整体 `derive(Serialize/Deserialize)`，故持久化拆出 `EventLog`（仅含 `events` + `next_id`）。这是"水之无定形"的体现——订阅关系流动不落盘，事件历史沉淀落盘。

### 6.3 zd-event-test（证道/基础验证-域/事件测试-府）

只测 hd-event 府级公共 API。

园内 `事件测试.rs`：

```rust
use std::sync::{Arc, Mutex};
use hd_event::EventBus;

#[cfg(test)]
mod tests {
    use super::*;

    fn 临时路径(名: &str) -> String {
        std::env::temp_dir()
            .join(format!("hd_event_test_{名}.toml"))
            .to_string_lossy()
            .into_owned()
    }

    #[test]
    fn 发布事件后历史记录() {
        let mut bus = EventBus::new();
        let id = bus.发布("内存变更".into(), vec![("键".into(), "值".into())]);
        assert_eq!(bus.按id(id).unwrap().类型, "内存变更");
        assert_eq!(bus.历史().len(), 1);
    }

    #[test]
    fn 按类型订阅分发() {
        let mut bus = EventBus::new();
        let 计数 = Arc::new(Mutex::new(0));
        let c = 计数.clone();
        bus.订阅("内存变更", Arc::new(move |_e| { *c.lock().unwrap() += 1; }));
        bus.发布("内存变更".into(), vec![]);
        bus.发布("内存变更".into(), vec![]);
        assert_eq!(*计数.lock().unwrap(), 2);
    }

    #[test]
    fn 不匹配类型的处理器不被调用() {
        let mut bus = EventBus::new();
        let 计数 = Arc::new(Mutex::new(0));
        let c = 计数.clone();
        bus.订阅("规则命中", Arc::new(move |_e| { *c.lock().unwrap() += 1; }));
        bus.发布("内存变更".into(), vec![]);
        assert_eq!(*计数.lock().unwrap(), 0);
    }

    #[test]
    fn 事件按发布顺序记录() {
        let mut bus = EventBus::new();
        bus.发布("甲".into(), vec![]);
        bus.发布("乙".into(), vec![]);
        let 历史 = bus.历史();
        assert_eq!(历史[0].类型, "甲");
        assert_eq!(历史[1].类型, "乙");
    }

    #[test]
    fn 持久化往返() {
        let path = 临时路径("往返");
        let mut bus = EventBus::new();
        bus.发布("内存变更".into(), vec![("键".into(), "值".into())]);
        bus.保存(&path).unwrap();
        let loaded = EventBus::加载(&path).unwrap();
        assert_eq!(loaded.历史().len(), 1);
        assert_eq!(loaded.历史()[0].类型, "内存变更");
        std::fs::remove_file(&path).ok();
    }

    #[test]
    fn 加载后id延续不冲突() {
        let path = 临时路径("延续");
        let mut bus = EventBus::new();
        bus.发布("一".into(), vec![]);
        bus.保存(&path).unwrap();
        let mut loaded = EventBus::加载(&path).unwrap();
        let new_id = loaded.发布("二".into(), vec![]);
        assert_eq!(new_id, 2);
        std::fs::remove_file(&path).ok();
    }
}
```

> 注意：持久化相关测试用 `临时路径(名)` 生成独立文件名（`往返`/`延续`），避免并发测试互相覆盖（乾坤记忆引擎的教训）。

依赖：`hd-event`。
