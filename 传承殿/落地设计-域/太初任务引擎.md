## 0. 设计目标

在九根之**太初**下落地任务引擎，跑通"任务诞生 → 受理 → 状态生长"的最小闭环。

验证点：
1. 太初根下域 ≤ 3，代码只落园（无 `src`），crate 根为府级 `模块.rs`
2. 任务能创建（诞生）、能查询（受理）、能按合法状态机推进（生长）
3. 非法状态流转被拒绝（状态机约束生效）
4. 府可插拔：`TaskStore` 实现 `Component` 契约
5. 测试全在证道，只测 tc-task 府级公共 API

## 6. crate 设计（tc-task）

### 6.1 Task 数据模型（任务模型-殿/任务定义-阁/任务-数据-园）

园内 `任务数据.rs`：

```rust
use crate::任务模型_殿::状态定义_阁::状态_枚举_园::状态枚举::TaskStatus;
use crate::任务模型_殿::状态定义_阁::状态_枚举_园::状态枚举::当前时间戳;

/// 任务：太初之木，从无到有的存在
#[derive(Debug, Clone)]
pub struct Task {
    pub id: u64,
    pub title: String,
    pub description: String,
    pub status: TaskStatus,
    pub created_at: u64,
}

impl Task {
    pub fn 新建(id: u64, title: String, description: String, created_at: u64) -> Self {
        Task {
            id,
            title,
            description,
            status: TaskStatus::待受理,
            created_at,
        }
    }
}
```

> 说明：`TaskStatus`、`当前时间戳` 定义在 `状态枚举.rs`，经模块链引用。`created_at` 为秒级时间戳（简化，持久化与时间精度留待后续）。

### 6.2 TaskStatus 状态机（任务模型-殿/状态定义-阁/状态-枚举-园）

园内 `状态枚举.rs`：

```rust
/// 任务状态：待受理 → 进行中 → 已完成（木之生长）
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TaskStatus {
    待受理,
    进行中,
    已完成,
    已取消,
}

impl TaskStatus {
    /// 合法流转判断（状态机约束）
    pub fn 可流转到(&self, next: &TaskStatus) -> bool {
        matches!(
            (self, next),
            (TaskStatus::待受理, TaskStatus::进行中)
                | (TaskStatus::待受理, TaskStatus::已取消)
                | (TaskStatus::进行中, TaskStatus::已完成)
                | (TaskStatus::进行中, TaskStatus::已取消)
        )
    }
}

/// 当前秒级时间戳
pub fn 当前时间戳() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs()
}
```

### 6.3 TaskStore 内存仓库（任务仓库-殿/仓库实现-阁/仓库-模块-园）

园内 `仓库模块.rs`：

```rust
use std::collections::HashMap;
use hm_contract::Component;
use hm_error::{Error, Result};
use crate::任务模型_殿::任务定义_阁::任务_数据_园::任务数据::Task;
use crate::任务模型_殿::状态定义_阁::状态_枚举_园::状态枚举::{TaskStatus, 当前时间戳};

/// 任务仓库：内存登记任务，支持查询与状态推进
pub struct TaskStore {
    tasks: HashMap<u64, Task>,
    next_id: u64,
}

impl TaskStore {
    pub fn new() -> Self {
        TaskStore {
            tasks: HashMap::new(),
            next_id: 1,
        }
    }

    /// 任务诞生：创建并登记，返回任务 id
    pub fn 创建(&mut self, title: String, description: String) -> u64 {
        let id = self.next_id;
        self.next_id += 1;
        let task = Task::新建(id, title, description, 当前时间戳());
        self.tasks.insert(id, task);
        id
    }

    /// 按 id 查询任务（受理）
    pub fn 查询(&self, id: u64) -> Option<&Task> {
        self.tasks.get(&id)
    }

    /// 列出全部任务
    pub fn 全部(&self) -> Vec<&Task> {
        self.tasks.values().collect()
    }

    /// 状态推进（木之生长），非法流转返回错误
    pub fn 推进(&mut self, id: u64, next: TaskStatus) -> Result<()> {
        let task = self
            .tasks
            .get(&id)
            .ok_or_else(|| Error::Other(format!("任务 {id} 不存在")))?;
        if !task.status.可流转到(&next) {
            return Err(Error::Other(format!(
                "非法状态流转: {:?} → {:?}",
                task.status, next
            )));
        }
        self.tasks.get_mut(&id).unwrap().status = next;
        Ok(())
    }
}

impl Component for TaskStore {
    fn name(&self) -> &'static str { "任务仓库" }
}
```

依赖：`hm-error`、`hm-contract`。

### 6.4 zd-task-test（证道/基础验证-域/任务测试-府）

只测 tc-task 府级公共 API（`TaskStore::创建/查询/推进`、状态机约束）。

园内 `任务测试.rs`：

```rust
use tc_task::TaskStatus;
use tc_task::TaskStore;

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn 任务诞生后状态为待受理() {
        let mut store = TaskStore::new();
        let id = store.创建("第一个任务".into(), "验证诞生".into());
        let task = store.查询(id).unwrap();
        assert_eq!(task.title, "第一个任务");
        assert_eq!(task.status, TaskStatus::待受理);
    }

    #[test]
    fn 合法状态推进成功() {
        let mut store = TaskStore::new();
        let id = store.创建("推进任务".into(), "".into());
        assert!(store.推进(id, TaskStatus::进行中).is_ok());
        assert!(store.推进(id, TaskStatus::已完成).is_ok());
        assert_eq!(store.查询(id).unwrap().status, TaskStatus::已完成);
    }

    #[test]
    fn 非法状态流转被拒绝() {
        let mut store = TaskStore::new();
        let id = store.创建("非法流转".into(), "".into());
        // 待受理 → 已完成 非法
        assert!(store.推进(id, TaskStatus::已完成).is_err());
        // 状态不变
        assert_eq!(store.查询(id).unwrap().status, TaskStatus::待受理);
    }

    #[test]
    fn 取消流转成功() {
        let mut store = TaskStore::new();
        let id = store.创建("取消任务".into(), "".into());
        assert!(store.推进(id, TaskStatus::进行中).is_ok());
        assert!(store.推进(id, TaskStatus::已取消).is_ok());
        assert_eq!(store.查询(id).unwrap().status, TaskStatus::已取消);
    }

    #[test]
    fn 查询不存在的任务返回空() {
        let store = TaskStore::new();
        assert!(store.查询(999).is_none());
    }
}
```

依赖：`tc-task`。
