# 量劫·迭代引擎 落地设计

> **定位**：第三个落地模块。兑现五行之**火**（转化、焚炼、重生）——迭代是"时间中的变革"。核心职责：版本演进、迭代周期、迭代记录（焚炼完成即重生为已完成）。
>
> **状态**：v1.0 · 2026-09-04
>
> **上游契约**：`传承殿/已定契约-域/已定契约.md`（实现必须遵守）
>
> **组织规则**：`rules/代码组织规则.md`（规模上限、模块.rs 汇总、证道只测府级）
>
> **前置**：鸿蒙基础设施、太初任务引擎均已实现并验收通过，复用其 hm-error、hm-contract 与「模块汇总 + 证道测府级」范式。

---

## 0. 设计目标

在九根之**量劫**下落地迭代引擎，跑通"版本演进 → 迭代开启 → 焚炼完成"的最小闭环。

验证点：
1. 量劫根下域 ≤ 3，代码只落园（无 `src`），crate 根为府级 `模块.rs`
2. 版本能递增（主/次/修订）、能显示（`主.次.修订`）
3. 迭代能开启（进行中）、能完成（已完成）、能放弃，非法流转被拒绝
4. 当前版本能正确指向「最新已完成的迭代」的版本
5. 府可插拔：`IterationLog` 实现 `Component` 契约
6. 测试全在证道，只测 lj-iteration 府级公共 API

## 1. 范围

### 本次落地（必须完成）
- 量劫根下 1 个域、1 个府（crate `lj-iteration`）
- `Version` 语义化版本（主.次.修订）+ 递增 + Display
- `Iteration` 迭代记录 + `迭代状态` 状态机（进行中 → 已完成/已放弃）
- `IterationLog` 迭代日志（开启/完成/放弃/查询/历史/当前版本）
- 证道新增测试府 `zd-iteration-test`，测 lj-iteration 府级 API
- 验收：`cargo build` 通过、`cargo test` 通过

### 本次不做（后续模块）
- **木生火联动**：任务完成积累驱动迭代（依赖太初 tc-task 的信号回调，后续）
- **重构触发**：技术债务模型、焚炼阈值（后续，需债务度量）
- **持久化**：内存存储，落盘留待**乾坤·记忆引擎**（土·承载）
- 火生土联动：迭代产出沉淀为记忆（依赖乾坤，后续）

## 6. crate 设计（lj-iteration）

### 6.1 Version 语义化版本（版本定义-殿/版本模型-阁/版本-数据-园）

园内 `版本数据.rs`：

```rust
/// 语义化版本：主.次.修订（火之演进刻度）
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub struct Version {
    pub 主: u32,
    pub 次: u32,
    pub 修订: u32,
}

impl Version {
    pub fn new(主: u32, 次: u32, 修订: u32) -> Self {
        Version { 主, 次, 修订 }
    }

    /// 主版本演进（重大变革，归零次与修订）
    pub fn 递增主(&self) -> Self {
        Version { 主: self.主 + 1, 次: 0, 修订: 0 }
    }

    /// 次版本演进（新能力，归零修订）
    pub fn 递增次(&self) -> Self {
        Version { 主: self.主, 次: self.次 + 1, 修订: 0 }
    }

    /// 修订演进（修复）
    pub fn 递增修订(&self) -> Self {
        Version { 主: self.主, 次: self.次, 修订: self.修订 + 1 }
    }
}

impl std::fmt::Display for Version {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{}.{}.{}", self.主, self.次, self.修订)
    }
}
```

### 6.2 Iteration + 迭代状态（迭代记录-殿/迭代定义-阁/迭代-数据-园）

园内 `迭代数据.rs`：

```rust
use crate::版本定义_殿::Version;

/// 迭代状态：进行中 → 已完成 / 已放弃（火之焚炼与重生）
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum 迭代状态 {
    进行中,
    已完成,
    已放弃,
}

/// 迭代：一次版本演进记录（火之变革）
#[derive(Debug, Clone)]
pub struct Iteration {
    pub id: u64,
    pub version: Version,
    pub 变更说明: String,
    pub status: 迭代状态,
    pub created_at: u64,
}

impl Iteration {
    pub fn 新建(id: u64, version: Version, 变更说明: String, created_at: u64) -> Self {
        Iteration {
            id,
            version,
            变更说明,
            status: 迭代状态::进行中,
            created_at,
        }
    }
}

/// 当前秒级时间戳
pub fn 当前时间戳() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs()
}
```

### 6.3 IterationLog 迭代日志（迭代记录-殿/迭代日志-阁/日志-模块-园）

园内 `日志模块.rs`：

```rust
use std::collections::HashMap;
use hm_contract::Component;
use hm_error::{Error, Result};
use crate::版本定义_殿::Version;
use crate::迭代记录_殿::{Iteration, 迭代状态, 当前时间戳};

/// 迭代日志：登记版本演进历史，追踪当前版本
pub struct IterationLog {
    iterations: HashMap<u64, Iteration>,
    next_id: u64,
}

impl IterationLog {
    pub fn new() -> Self {
        IterationLog {
            iterations: HashMap::new(),
            next_id: 1,
        }
    }

    /// 开启迭代（火之变革开始），返回迭代 id
    pub fn 开启(&mut self, version: Version, 变更说明: String) -> u64 {
        let id = self.next_id;
        self.next_id += 1;
        let it = Iteration::新建(id, version, 变更说明, 当前时间戳());
        self.iterations.insert(id, it);
        id
    }

    /// 完成迭代（焚炼完成，重生为已完成）
    pub fn 完成(&mut self, id: u64) -> Result<()> {
        let it = self
            .iterations
            .get(&id)
            .ok_or_else(|| Error::Other(format!("迭代 {id} 不存在")))?;
        if it.status != 迭代状态::进行中 {
            return Err(Error::Other(format!("迭代 {id} 状态非法: {:?}", it.status)));
        }
        self.iterations.get_mut(&id).unwrap().status = 迭代状态::已完成;
        Ok(())
    }

    /// 放弃迭代
    pub fn 放弃(&mut self, id: u64) -> Result<()> {
        let it = self
            .iterations
            .get(&id)
            .ok_or_else(|| Error::Other(format!("迭代 {id} 不存在")))?;
        if it.status != 迭代状态::进行中 {
            return Err(Error::Other(format!("迭代 {id} 状态非法: {:?}", it.status)));
        }
        self.iterations.get_mut(&id).unwrap().status = 迭代状态::已放弃;
        Ok(())
    }

    /// 按 id 查询迭代
    pub fn 查询(&self, id: u64) -> Option<&Iteration> {
        self.iterations.get(&id)
    }

    /// 演进历史（全部迭代）
    pub fn 历史(&self) -> Vec<&Iteration> {
        self.iterations.values().collect()
    }

    /// 当前版本：最新已完成迭代的版本；无则返回 0.0.0
    pub fn 当前版本(&self) -> Version {
        self.iterations
            .values()
            .filter(|it| it.status == 迭代状态::已完成)
            .map(|it| it.version)
            .max()
            .unwrap_or(Version::new(0, 0, 0))
    }
}

impl Component for IterationLog {
    fn name(&self) -> &'static str { "迭代日志" }
}
```

依赖：`hm-error`、`hm-contract`。

### 6.4 zd-iteration-test（证道/基础验证-域/迭代测试-府）

只测 lj-iteration 府级公共 API。

园内 `迭代测试.rs`：

```rust
use lj_iteration::Version;
use lj_iteration::IterationLog;
use lj_iteration::迭代状态;

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn 版本递增正确() {
        let v = Version::new(1, 2, 3);
        assert_eq!(v.递增主(), Version::new(2, 0, 0));
        assert_eq!(v.递增次(), Version::new(1, 3, 0));
        assert_eq!(v.递增修订(), Version::new(1, 2, 4));
    }

    #[test]
    fn 版本显示格式() {
        assert_eq!(Version::new(1, 2, 3).to_string(), "1.2.3");
    }

    #[test]
    fn 开启迭代后状态为进行中() {
        let mut log = IterationLog::new();
        let id = log.开启(Version::new(1, 0, 0), "首个版本".into());
        assert_eq!(log.查询(id).unwrap().status, 迭代状态::进行中);
    }

    #[test]
    fn 完成迭代后当前版本更新() {
        let mut log = IterationLog::new();
        let id = log.开启(Version::new(1, 0, 0), "首个版本".into());
        assert!(log.完成(id).is_ok());
        assert_eq!(log.当前版本(), Version::new(1, 0, 0));
    }

    #[test]
    fn 放弃迭代不影响当前版本() {
        let mut log = IterationLog::new();
        let id = log.开启(Version::new(1, 0, 0), "废弃版本".into());
        assert!(log.放弃(id).is_ok());
        assert_eq!(log.当前版本(), Version::new(0, 0, 0));
    }

    #[test]
    fn 重复完成已完成的迭代被拒绝() {
        let mut log = IterationLog::new();
        let id = log.开启(Version::new(1, 0, 0), "".into());
        assert!(log.完成(id).is_ok());
        assert!(log.完成(id).is_err());
    }

    #[test]
    fn 演进历史与当前版本取最新() {
        let mut log = IterationLog::new();
        let a = log.开启(Version::new(1, 0, 0), "一".into());
        let b = log.开启(Version::new(2, 0, 0), "二".into());
        log.完成(a).unwrap();
        log.完成(b).unwrap();
        assert_eq!(log.历史().len(), 2);
        assert_eq!(log.当前版本(), Version::new(2, 0, 0));
    }
}
```

依赖：`lj-iteration`。
