# 乾坤·记忆引擎 落地设计

> **定位**：第四个落地模块。兑现五行之**土**（承载、稳定）——记忆是"空间中的承载"。核心职责：记忆承载、经验沉淀、落盘持久化。
>
> **状态**：v1.1 · 2026-09-04
>
> **上游契约**：`传承殿/已定契约-域/已定契约.md`（实现必须遵守）
>
> **组织规则**：`.codeartsdoer/rule/代码组织规则.mdc`（规模上限、模块.rs 汇总、证道只测府级）
>
> **前置**：鸿蒙、太初、量劫均已实现并验收通过。**本模块首次兑现持久化（落盘）**——前两个引擎均将持久化留待本模块。

## 0. 设计目标

在九根之**乾坤**下落地记忆引擎，跑通"记忆写入 → 承载查询 → 落盘 → 加载还原"的最小闭环。

验证点：
1. 乾坤根下域 ≤ 3，代码只落园（无 `src`），crate 根为府级 `模块.rs`
2. 记忆能写入（承载）、能查询（按 id / 按标签）
3. 记忆库能落盘（保存）并从文件还原（加载），往返内容一致
4. 加载后 id 延续不冲突（next_id 持久化）
5. 府可插拔：`MemoryStore` 实现 `Component` 契约
6. 测试全在证道，只测 qk-memory 府级公共 API

## 6. crate 设计（qk-memory）

### 6.1 Memory 记忆条目（记忆定义-殿/记忆模型-阁/记忆-数据-园）

园内 `记忆数据.rs`：

```rust
use serde::{Deserialize, Serialize};

/// 记忆：土之承载，经验沉淀的单元
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Memory {
    pub id: u64,
    pub 内容: String,
    pub 标签: String,
    pub created_at: u64,
}

impl Memory {
    pub fn 新建(id: u64, 内容: String, 标签: String, created_at: u64) -> Self {
        Memory { id, 内容, 标签, created_at }
    }
}

/// 当前秒级时间戳
pub fn 当前时间戳() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs()
}
```

### 6.2 MemoryStore 记忆库（记忆承载-殿/记忆库-阁/库-模块-园）

园内 `库模块.rs`：

```rust
use hm_contract::Component;
use hm_error::{Error, Result};
use serde::{Deserialize, Serialize};
use crate::记忆定义_殿::{Memory, 当前时间戳};

/// 记忆库：承载记忆，支持落盘持久化
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MemoryStore {
    memories: Vec<Memory>,
    next_id: u64,
}

impl MemoryStore {
    pub fn new() -> Self {
        MemoryStore {
            memories: Vec::new(),
            next_id: 1,
        }
    }

    /// 写入记忆，返回记忆 id
    pub fn 写入(&mut self, 内容: String, 标签: String) -> u64 {
        let id = self.next_id;
        self.next_id += 1;
        self.memories.push(Memory::新建(id, 内容, 标签, 当前时间戳()));
        id
    }

    /// 按 id 查询
    pub fn 查询(&self, id: u64) -> Option<&Memory> {
        self.memories.iter().find(|m| m.id == id)
    }

    /// 按标签查询
    pub fn 按标签(&self, 标签: &str) -> Vec<&Memory> {
        self.memories.iter().filter(|m| m.标签 == 标签).collect()
    }

    /// 全部记忆
    pub fn 全部(&self) -> Vec<&Memory> {
        self.memories.iter().collect()
    }

    /// 保存到文件（落盘）
    pub fn 保存(&self, path: &str) -> Result<()> {
        let content = toml::to_string(self)
            .map_err(|e| Error::Other(format!("序列化记忆失败: {e}")))?;
        std::fs::write(path, content)
            .map_err(|e| Error::Other(format!("写入记忆文件 {path} 失败: {e}")))?;
        Ok(())
    }

    /// 从文件加载（还原）
    pub fn 加载(path: &str) -> Result<Self> {
        let content = std::fs::read_to_string(path)
            .map_err(|e| Error::Other(format!("读取记忆文件 {path} 失败: {e}")))?;
        toml::from_str(&content)
            .map_err(|e| Error::Other(format!("解析记忆文件失败: {e}")))
    }
}

impl Component for MemoryStore {
    fn name(&self) -> &'static str { "记忆库" }
}
```

依赖：`hm-error`、`hm-contract`、`serde`、`toml`。

### 6.3 zd-memory-test（证道/基础验证-域/记忆测试-府）

只测 qk-memory 府级公共 API。

园内 `记忆测试.rs`：

```rust
#[cfg(test)]
mod tests {
    use qk_memory::MemoryStore;

    fn 临时路径(名: &str) -> String {
        std::env::temp_dir()
            .join(format!("qk_memory_test_{名}.toml"))
            .to_string_lossy()
            .into_owned()
    }

    #[test]
    fn 写入记忆后可查询() {
        let mut store = MemoryStore::new();
        let id = store.写入("第一条经验".into(), "经验".into());
        let m = store.查询(id).unwrap();
        assert_eq!(m.内容, "第一条经验");
        assert_eq!(m.标签, "经验");
    }

    #[test]
    fn 按标签查询() {
        let mut store = MemoryStore::new();
        store.写入("经验A".into(), "经验".into());
        store.写入("经验B".into(), "经验".into());
        store.写入("规则X".into(), "规则".into());
        assert_eq!(store.按标签("经验").len(), 2);
        assert_eq!(store.按标签("规则").len(), 1);
    }

    #[test]
    fn 查询不存在的记忆返回空() {
        let store = MemoryStore::new();
        assert!(store.查询(999).is_none());
    }

    #[test]
    fn 持久化往返() {
        let path = 临时路径("往返");
        let mut store = MemoryStore::new();
        store.写入("待持久化".into(), "经验".into());
        store.保存(&path).unwrap();
        let loaded = MemoryStore::加载(&path).unwrap();
        assert_eq!(loaded.全部().len(), 1);
        assert_eq!(loaded.查询(1).unwrap().内容, "待持久化");
        std::fs::remove_file(&path).ok();
    }

    #[test]
    fn 加载后id延续不冲突() {
        let path = 临时路径("延续");
        let mut store = MemoryStore::new();
        store.写入("一".into(), "经验".into());
        store.保存(&path).unwrap();
        let mut loaded = MemoryStore::加载(&path).unwrap();
        let new_id = loaded.写入("二".into(), "经验".into());
        assert_eq!(new_id, 2);
        std::fs::remove_file(&path).ok();
    }
}
```

依赖：`qk-memory`。

## 7. 依赖关系（单向、无环）

```
zd-memory-test ──> qk-memory ──> hm-contract ──> hm-error
                      │
                      └──> serde / toml
```
