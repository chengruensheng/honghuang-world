## 一、项目形态

- **后端主体**：Rust Cargo workspace（`resolver = "2"`、`edition 2021`），HTTP 层为 **axum 0.8**（配套 tokio / tower-http / async-stream）。桌面壳已移除。呈现层以**纯静态呈现域**形式存在（`乾坤/观星呈现-域`，无 Rust 代码），由 `对外契约.toml` 的 `static_dir` 挂载，不进 workspace。
- **前后端零耦合（呈现面外置）**：后端对外暴露的「呈现参数」——CORS 来源白名单 / 静态资源托管目录 / SSE 并发上限——由独立配置文件 `对外契约.toml` 唯一声明；增删客户端只改该文件，不改任何 Rust 代码。
- **契约单一真相源（事件词表）**：AG-UI 事件词表/交互协议属「契约」，由 Rust 契约 crate **`hm-agui`** 作单一真相源，**不**放进 `对外契约.toml`。
- **默认网络参数**：端口 `8321`、bind `127.0.0.1`（见 hm-config `default.toml`；非 127.0.0.1 且未设 token 时拒绝启动）。
- **对外消费方统一称「客户端」**；仓库内的静态呈现层称「呈现域」（`乾坤/观星呈现-域`）。

| 加载时机 | 运行时：工作目录存在同名 `对外契约.toml` 则按其加载；否则用**编译期嵌入默认**（`include_str!`，不依赖 cwd）。解析失败告警并回退内置默认。 |
| 消费点 | ① `hm_http::构建路由(状态, 对外)`：按 `cors_origins` / `static_dir` 条件化装配 CORS 与静态托管；② `hm_http::启动数据服务(..., 对外)`；③ 启动模块 `数据状态.设置并发上限(契约.对外.sse_max)` |
| `cors_origins` | 允许跨源来源白名单；**空数组 = 不启用 CORS 中间件**（纯脚本/同源客户端） |
| `static_dir` | 静态资源托管目录；**空串 = 不托管**（纯 API，零前端依赖） |
| `sse_max` | SSE 并发连接上限；**默认 10**；**0 = 不限制**（`设置并发上限` 内 0→`usize::MAX`） |
| 当前值（快照） | `cors_origins = []`、`static_dir = ""`、`sse_max = 10`（纯 API 形态） |
