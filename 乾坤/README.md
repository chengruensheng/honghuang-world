# 乾坤（土 · 记忆引擎 + 界面呈现）

五行本体之一，承载「空间、记忆、稳定、呈现」语义。根下两域：

- **记忆管理-域**：记忆引擎（写入 / 查询 / 落盘持久化），crate `qk-memory`，已落地
- **界面呈现-域**：界面呈现（视觉背景 + 区域布局 + 页面组装），crate `qk-web`，落地中
  - 视觉背景-殿：设计令牌 + 页面底色（零布局）
  - 区域布局-殿：槽位网格 + 挂载契约（零色彩，只引用令牌）
  - 页面承载-殿：组装自包含页面，`落盘页面(目录)` 写出门面.html
  - 预览：`cargo run -p qk-web --bin 界面-预览`，产物在 `target/界面-预览/`
  - 组件隔离约定：组件只能经 `乾坤界面.挂载(槽位名, 节点)` 进入槽位，不得触碰 `.界面-*` 布局结构
