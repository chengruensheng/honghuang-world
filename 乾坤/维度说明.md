### 监控界面-府 · 步骤直播视图（索引回链）

- 落位：`呈现-域/监控界面-府/`（Rust lib crate，`入口.rs` lib 根 + `Cargo.toml`（lib=`jiankong_fu`，入 workspace）+ 四殿：`类型-定义-殿` / `数据-抓取-殿` / `视图-装配-殿` / `输出-呈现-殿`）；静态资源三件套 `index.html / app.js / style.css` 经 `include_str!` / `include_bytes!` 编译期内嵌
- 端口：8080（默认）；启动方式 `cargo run -p mingling_fu -- 监控 启动`（命令操作府子命令）或独立 bin `cargo run -p jiankong_fu`，可传端口参数
- 数据源：**三源白箱**，经各府 lib 根符号读取（止步 lib 根，不深链园内文件）——
  - `shihai_fu::`（识海承载-府：格位 / 编码 / 归档 / 命中率 / 事件流）
  - `jiance_fu::`（观测探针-府：观测记录 / span / 跨界异常，路径 `鸿蒙/基础设施-域/观测探针-府`）
  - `rizhi_fu::`（日志记录-府：兜底构建 / 流式渲染队列）
- 推送：D1 SSE（`/api/events/stream`，axum::response::sse），不轮询；首屏 `/api/events/recent?limit=200` 倒序拉；三源合并 LOD 渲染（L0/L1/L2）
- 视图：右区步骤面板 = 顶 tab「时间线（默认） | 任务树（默认折叠）」
- 形态：事件贴底、视口对齐底沿、超 N=200 进回收池
- 重点：阶段/验收/失败/版本存档 = 重点卡(字号+前缀符)；工具调用/状态推进 = 细行可展；失败统一 `⚠` 前缀
- aside 与右区分工：aside 仅作索引(点切任务树 + 锚定顶卡)；tab 控右区视图
