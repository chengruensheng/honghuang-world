# 装配配置说明

> 配置管理-府 · `.上下文/装配.json` 字段手册（首章：字段与默认值）
>
> 本章按字段逐条说明装配配置（`装配配置` 结构体）的字段名、类型、默认值与含义，作为阶段 4 Profile 装配的单一事实源对照表。

---

## 一、字段总览

| 序号 | 字段名          | 类型            | 默认值                          | 含义简述                           |
| ---- | --------------- | --------------- | ------------------------------- | ---------------------------------- |
| 1    | `阶段`          | `阶段值` 枚举   | `乙`                            | 世界阶段（甲=功能优先 / 乙=开自动优化） |
| 2    | `启用扩展`      | `Vec<扩展开关>` | `[巡世, 进化, 观测]`            | 启用的世界扩展点                   |
| 3    | `模型提供者`    | `String`        | `"http"`                        | 全局模型提供者注册表的键名         |
| 4    | `角色册路径`    | `String`        | 见下文                          | 角色册 JSON 的相对工作区根路径     |
| 5    | `合法产物扩展名`| `Vec<String>`   | 见下文（13 种）                 | 世界认作合法产物的文件扩展名集合   |

> **数据驱动原则**：新增世界行为不必改代码，能用配置表达优先改 `.上下文/装配.json`。本章是字段事实基线，代码侧以 `鸿蒙/世界配置 - 域/配置管理-府/类型-定义-殿/模型-声明-阁/声明-集中-园/声明集中.rs` 中的 `装配配置` 结构体为准。

## 二、字段详细说明

### 2.1 `阶段`

- **类型**：`阶段值` 枚举（`pub enum 阶段值`）
- **取值范围**：
  - `甲`：功能优先期，关闭自动优化（不启用 巡世/进化）
  - `乙`：开 巡世/进化的自动优化期
- **默认值**：`乙`
- **默认值来源**：`装配配置::default()` 中显式赋值为 `阶段值::乙`
- **含义**：决定世界是否进入自动发现（巡世）与自我进化（进化）阶段。甲阶段只跑主流程；乙阶段在此之上加挂 巡世/进化 扩展点。
- **读取入口**：`peizhi_fu::读装配().阶段`

---

### 2.2 `启用扩展`

- **类型**：`Vec<扩展开关>`（元素为 `pub enum 扩展开关`）
- **取值范围**（扩展开关枚举的三个变体）：
  - `巡世`：天道巡世扫描（自动发现可优化点）
  - `进化`：自动进化环（基于巡世结果归因并改动）
  - `观测`：可观测扩展点（事件总线监听、装配呈现等）
- **默认值**：`vec![扩展开关::巡世, 扩展开关::进化, 扩展开关::观测]`（三项全开）
- **默认值来源**：`装配配置::default()` 中显式赋值为上述三元素向量
- **含义**：逐项开关各扩展点。甲阶段装配通常置空数组（不启 巡世/进化），乙阶段默认全开；可按需要单独关闭某项。
- **读取入口**：`peizhi_fu::读装配().启用扩展`
- **判定入口**：`peizhi_fu::启用扩展(&装配, &扩展开关::Xxx)` 返回 `bool`

---

### 2.3 `模型提供者`

- **类型**：`String`
- **默认值**：`"http"`
- **默认值来源**：`装配配置::default()` 中显式赋值为 `"http".to_string()`
- **含义**：全局模型提供者注册表（`moxing_fu::全局提供者注册表`）的键名。运行时据此查找具体提供者实现（当前默认 `http`，未来可扩展 `mock`/`azure` 等）。
- **读取入口**：`peizhi_fu::读装配().模型提供者`
- **当前已注册名**：见 `号令 装配 检查` 命令的「模型提供者已注册」行（实际注册状态可能多于装配声明）。

---

### 2.4 `角色册路径`

- **类型**：`String`（相对工作区根的路径）
- **默认值**：

  ```text
  鸿蒙/基础设施 - 域/道术施展-府/角色-卡册-殿/角色-登记-阁/登记-落册-园/角色册.json
  ```

- **默认值来源**：`装配配置::default()` 中显式赋值为上述路径字符串
- **含义**：阶段 3 全局角色册（`daoshu_fu::全局角色册`）的装载源 JSON 路径。相对工作区根解析（环境变量 `WORLD_WORKSPACE_ROOT` 优先，回退当前目录）。
- **读取入口**：`peizhi_fu::读装配().角色册路径`
- **失败兜底**：路径所指文件不存在或解析失败时，全局角色册保持空，不影响世界运行。

---

### 2.5 `合法产物扩展名`

- **类型**：`Vec<String>`（每元素为带点的扩展名字符串，如 `".rs"`）
- **默认值**（13 种，由 `默认扩展名()` 函数返回）：

  | 类别     | 扩展名                                  |
  | -------- | --------------------------------------- |
  | 代码     | `.rs`                                   |
  | 文档     | `.md`、`.txt`                           |
  | 配置     | `.json`、`.toml`、`.yaml`、`.yml`       |
  | 脚本     | `.py`、`.sh`、`.ps1`、`.bat`            |
  | 静态网页 | `.html`、`.css`、`.js`                  |

  完整列表：`[".rs", ".md", ".json", ".toml", ".yaml", ".yml", ".txt", ".py", ".sh", ".ps1", ".bat", ".html", ".css", ".js"]`

- **默认值来源**：`声明集中.rs` 中 `pub fn 默认扩展名()`；结构体字段上挂 `#[serde(default = "默认扩展名")]`。
- **含义**：世界认作「合法产物」的文件扩展名集合。涉及路径净化、兜底提取、内容摘要等功能（如终裁、要求化）据此识别产物类型。
- **数据驱动特性**：新增文件类型只改配置不改代码。例如要支持 `.vue`，追加 `".vue"` 到本字段即可。
- **向后兼容**：旧版 `.上下文/装配.json` 若无本字段，serde default 自动兜底为 `默认扩展名()`，不会因字段缺失导致反序列化失败。
- **读取入口**：`peizhi_fu::读装配().合法产物扩展名`

## 四、装配加载与兜底

- **文件位置**：`.上下文/装配.json`（相对工作区根，环境变量 `WORLD_WORKSPACE_ROOT` 优先）。
- **加载入口**：`peizhi_fu::读装配()`。
- **兜底行为**（按顺序）：
  1. 文件不存在 → 返回 `装配配置::default()`（debug 级日志记录）。
  2. 文件存在但 JSON 解析失败 → 返回 `装配配置::default()`（warn 级日志记录错误原因）。
  3. 解析成功 → 返回该装配（debug 级日志记录路径）。
- **字段级兜底**：单字段缺失由 serde `#[serde(default = "...")]` 局部兜底（目前仅 `合法产物扩展名` 挂了此特性，其他字段缺失将触发整体解析失败并回默认）。

  - 全局提供者注册表的实际已注册名

  - 事件总线监听数（验收/裁决、重投/循环）
  - 府树（9 府静态清单）
