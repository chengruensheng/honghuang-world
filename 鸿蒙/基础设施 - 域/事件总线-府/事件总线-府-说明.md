# 事件总线 - 府（shijian_fu）子系统说明

> 路径：`鸿蒙/基础设施 - 域/事件总线-府`
> crate 名：`shijian_fu`，库根：`入口.rs`
> 对齐对象：DeepSeek Harness 事件域（`docs/architecture.zh.md §事件` / `tool-execution-pipeline.zh.md`）

---

## 一、总览

### 1.1 本质

进程内**实时扩展点**——事件注册表 + 分发，让横切关注点（护栏 / 审批 / 观测 / 重试）以监听器挂入而非内嵌。

- 命名事件总线：通知（emit，观察）/ 串行（serial，按序 Err 中止）。
- 类型化流水线 `流水线<T>`：waterfall 语义（监听器可改写载荷，Err 即中止）。
- 单调守卫：deny-or-abstain，identity 保护。
- 注销句柄：drop 或手动 `.注销()` 自动从注册表移除监听（可逆副作用，对齐 Cordis disposer）。

### 1.2 与「识海承载-府 事件流」的分工

| 维度 | 事件总线-府 | 识海承载-府 事件流 |
|------|-------------|--------------------|
| 持久性 | 内存态（注册表 + 闭包） | 落盘 `.上下文/事件流.jsonl`（append-only） |
| 用途 | 实时横切扩展点 | 持久事实源（事后回看/审计/重放） |
| 类型 | 类型擦除 `dyn Any + Send` | 类型化 JSON 行 |
| 关系 | 不混淆；总线只触发当下行为 | 流记录"发生了什么" |

### 1.3 与 DeepSeek Harness 工具流水线对齐

四段时序：**预执行（pre-execute）→ 守卫们（guards）→ 执行（execute）→ 后执行（post-execute）→ 落定（result）**，对齐 `tool-execution-pipeline.zh.md`。

## 二、事件总线（命名事件 · 通知 / 串行分发）

### 2.1 概念

- 注册表：`HashMap<事件名, Vec<注册项>>`，外层 `RwLock`（并发安全）。
- 注册项含：分发模式、回调、序号（注册单调递增）。
- 分发时按**注册顺序**（序号升序）调用；不引入额外调度线程，并行由调用方线程表达。
- 注册量小、分发频率低，分发持读锁可接受；注册/注销持写锁。

### 2.2 两种分发模式

| 模式 | 监听器 Err 语义 | 典型用途 |
|------|----------------|----------|
| `分发模式::通知` | 记录日志，不中止后续 | 观测/审计/重投（事后行为） |
| `分发模式::串行` | 任一 Err 即中止（带原因） | 校验/审批/守卫（决策链） |

### 2.3 关键 API 表

| 符号 | 签名 | 行为 |
|------|------|------|
| `事件总线::新()` | `pub fn 新() -> Self` | 新建空总线（`Default` 已实现）。 |
| `事件总线::注册` | `pub fn 注册(&self, 事件: &str, 模式: 分发模式, 回调: 回调) -> 注销句柄` | 注册监听，返回注销句柄（drop 自动移除）；同事件同模式按注册顺序分发。 |
| `事件总线::通知` | `pub fn 通知(&self, 事件: &str, 载荷: &mut 载荷)` | 通知分发（emit）：观察，按注册顺序调用；监听器 Err 只记录不中止。 |
| `事件总线::串行` | `pub fn 串行(&self, 事件: &str, 载荷: &mut 载荷) -> Result<(), String>` | 串行分发：按注册顺序调用；任一 Err 即中止。 |
| `事件总线::监听数` | `pub fn 监听数(&self, 事件: &str) -> usize` | 事件上的监听器数（观测用）。 |
| `全局总线()` | `pub fn 全局总线() -> &'static 事件总线` | 进程级单例（`OnceLock`），供各府共享同一注册表；事件名由各府声明（如「验收/裁决」「重投/循环」）。 |

### 2.4 载荷类型约定

```rust
pub type 载荷 = dyn std::any::Any + Send;
pub type 回调 = Box<dyn Fn(&mut 载荷) -> Result<(), String> + Send + Sync>;
```

- 类型擦除（Any），由事件声明方约定具体类型并 downcast。
- 载荷须 `Send`（回调可跨线程），注册/分发在同一进程内完成。

## 三、`流水线<T>`（类型化 waterfall 短路语义）

### 3.1 概念

- 监听器按**注册顺序**执行，**任一 Err 即中止**（waterfall 短路）。
- 强类型载荷 `T`，**无 Any 开销**——类型擦除总线的"干净版"。
- 注册均返回 `注销句柄`：删除闭包捕获「项们弱引用 + 序号」，drop / 手动注销时从 `Vec` 实际移除。
- 并发安全：内部 `Arc<RwLock<Vec<流水线项<T>>>>`。

### 3.2 与事件总线的差异

| 维度 | 事件总线 | 流水线<T> |
|------|----------|-----------|
| 载荷 | `dyn Any + Send`（类型擦除） | 泛型 `T`（类型化） |
| 命名空间 | 命名事件（事件名字符串） | 实例级（一个 `流水线<T>` 对象） |
| 模式 | 通知 / 串行二选一 | 统一 waterfall（按序 Err 短路） |
| 典型用途 | 跨府事件（验收/裁决、重投/循环） | 工具流水线四段、命令守卫链 |

### 3.3 关键 API 表

| 符号 | 签名 | 行为 |
|------|------|------|
| `流水线::<T>::新()` | `pub fn 新() -> Self` | 新建空流水线（`Default` 已实现；`T: 'static`）。 |
| `流水线::注册` | `pub fn 注册(&mut self, 监听: impl Fn(&mut T) -> Result<(), String> + Send + Sync + 'static) -> 注销句柄` | 注册监听，返回注销句柄（drop 自动移除）。 |
| `流水线::执行` | `pub fn 执行(&self, 载荷: &mut T) -> Result<(), String>` | 执行链：按注册顺序执行，任一 Err 即中止（waterfall 语义）。 |
| `流水线::长度` | `pub fn 长度(&self) -> usize` | 链上监听器数（观测用）。 |

## 四、工具流水线（四段 + 守卫裁决）

### 4.1 概念

类型化流水线的"业务定型"——把工具调用挂成 **预执行 → 守卫们 → 执行 → 后执行 → 落定** 四段，对齐 `tool-execution-pipeline.zh.md`：

1. **预执行**（`流水线<工具请求>`）：审批 / 护栏 / 沙箱准备；waterfall，任一 Err → 工具体跳过。
2. **守卫们**（`Vec<Arc<dyn 守卫>>`）：单调守卫 deny-or-abstain，逐个裁决；首个 `放行` 即止，全部 `弃权` 视为放行，`拒绝` 立即返回错误。
3. **执行**（`执行器`）：真实工具函数体，映射「道术施展-府 手脚-施展-殿」的函数（如 `原子-写入`、`流式-检索`）。
4. **后执行**（`流水线<工具结果>`）：结果改写 / 补上下文 / 观测留痕；waterfall，可改 `结果.文本`。
5. **落定**：冻结 `工具结果`，返回模型可见。

### 4.2 守卫裁决三态

```rust
pub enum 裁决 {
    放行,                 // 本次请求通过（守卫只裁决一次）
    拒绝(String),         // 拦截，附原因
    弃权,                 // 不表态，交下一守卫或默认放行
}
```

- **identity 保护**：守卫只应裁决自己的职责面，跨面交给别的守卫。
- **deny-or-abstain**：默认放行；想要拦截必须显式 `拒绝`。

### 4.3 关键 API 表

| 符号 | 签名 | 行为 |
|------|------|------|
| `工具流水线::新` | `pub fn 新(执行: impl Fn(&工具请求) -> Result<工具结果, String> + Send + Sync + 'static) -> Self` | 构造（执行器必填；预执行/守卫/后执行默认空，可后注册）。 |
| `工具流水线::预执行注册` | `pub fn 预执行注册(&mut self, 监听: impl Fn(&mut 工具请求) -> Result<(), String> + Send + Sync + 'static) -> 注销句柄` | 预执行段注册监听（审批 / 护栏挂这里）。 |
| `工具流水线::加守卫` | `pub fn 加守卫(&mut self, 守卫: std::sync::Arc<dyn 守卫>)` | 守卫段追加守卫。 |
| `工具流水线::后执行注册` | `pub fn 后执行注册(&mut self, 监听: impl Fn(&mut 工具结果) -> Result<(), String> + Send + Sync + 'static) -> 注销句柄` | 后执行段注册监听（结果改写 / 观测留痕挂这里）。 |
| `工具流水线::执行` | `pub fn 执行(&self, 请求: &工具请求) -> Result<工具结果, String>` | 执行完整流水线：预执行 → 守卫们 → 执行 → 后执行 → 落定。 |
| `工具请求::新` | `pub fn 新(调用名, 参数: serde_json::Value, 工作区根: PathBuf, 涉及路径: Vec<String>) -> Self` | 构造工具请求。 |
| `工具结果::新` | `pub fn 新(文本: impl Into<String>) -> Self` | 构造工具结果；`默认()` 返回空结果。 |
| `守卫::裁决` | `fn 裁决(&self, 请求: &工具请求) -> 裁决` | trait 方法；实现方对请求做单调裁决。 |

### 4.4 工具请求 / 工具结果字段

```rust
pub struct 工具请求 {
    pub 调用名: String,
    pub 参数: serde_json::Value,
    pub 工作区根: PathBuf,
    pub 涉及路径: Vec<String>,        // 守卫裁决依据之一
}

pub struct 工具结果 {
    pub 文本: String,                 // 模型可见文本
    pub 写入文件们: Vec<(String, u64)>, // 路径 + 字节数（审计/重投依据）
}
```

## 五、注销句柄（可逆副作用）

### 5.1 概念

- 注册返回的 `注销句柄` 捕获删除闭包：注册表弱引用 + 事件名 / 序号 + 序号；drop 或手动 `.注销()` 时从注册表**实际移除**对应项。
- 对齐 Cordis **disposer** 语义——注册是副作用，注销是反副作用，二者对称。
- 短句柄持锁、短闭包（仅 retain/retain_mut），不会跨线程卡顿。

### 5.2 关键 API 表

| 符号 | 签名 | 行为 |
|------|------|------|
| `注销句柄::注销` | `pub fn 注销(&mut self)` | 手动注销（幂等；drop 也会自动注销）。 |
| `Drop for 注销句柄` | `fn drop(&mut self) { self.注销(); }` | 作用域结束自动注销。 |
| `Debug for 注销句柄` | 手动实现 | 显示 `注销句柄{待注销}` / `注销句柄{已注销}`；不 derive（`FnOnce` 删除闭包不可克隆）。 |

### 5.3 用法范式

```rust
let 总线 = 全局总线();
let 句柄 = 总线.注册("验收/裁决", 分发模式::通知, Box::new(|载荷| {
    // 观测：记录"何时被裁决"，不阻断
    Ok(())
}));
// 句柄 离开作用域时自动从注册表移除
// 或提前：句柄.注销();
```

## 六、与 DeepSeek Harness 工具流水线对照表

| DeepSeek Harness | 事件总线-府 | 备注 |
|------------------|-------------|------|
| `EventBus.emit` | `事件总线::通知` | 观察型，不中止 |
| `EventBus.serial` | `事件总线::串行` | 决策链，任一 Err 中止 |
| `pre-execute hooks` | `工具流水线::预执行注册`（waterfall） | 审批 / 护栏 / 沙箱 |
| `guards` | `工具流水线::加守卫`（deny-or-abstain） | identity 保护 |
| `execute tool fn` | `工具流水线::执行`（`执行: 执行器`） | 真实工具函数体 |
| `post-execute hooks` | `工具流水线::后执行注册`（waterfall） | 结果改写 / 补上下文 |
| `result` | `工具结果`（冻结返回） | 模型可见 |
| Cordis `disposer` | `注销句柄`（drop 自动移除） | 可逆副作用 |
