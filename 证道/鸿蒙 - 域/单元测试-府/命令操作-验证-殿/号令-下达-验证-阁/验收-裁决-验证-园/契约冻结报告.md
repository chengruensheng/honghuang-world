# 契约冻结报告 — 验收-裁决-阁/批量-审验-园

> 本报告为「验收-裁决-验证-园」测试工程的契约前置冻结产物。所有结论以代码事实为准（证据：批量审验.rs 完整定义已在相关文件现状给出），LLM 仅负责结构化归档与可机器校验不变量提炼。
>
> 冻结范围：pub 入口签名、可见性、意图/裁决类型、Err 变体全集、序列化格式、持久化事务边界、trait 抽象判定、全局可变状态判定、并发隔离通道。
>
> 冻结生效后，测试侧不得本地重定义意图/裁决符号，不得跨过本报告引用的接口而自造；任何契约漂移须先升版本再改测试。

## 1. pub 入口签名（冻结快照）

### 1.1 主入口 — `mingling_fu::裁决验收`

- 文件：`乾坤/呈现-域/命令操作-府/号令-下达-殿/验收-裁决-阁/批量-审验-园/批量审验.rs`
- 路径：模块桥接 `批量审验` 暴露在 `mingling_fu` 库根
- 签名：`pub fn 裁决验收(要求id: &str, 结论: &str, 意见: &str) -> String`
- 可见性：`pub fn`（库根导出符号）
- 行为：
  - 入参 `结论` ∈ {"通过", "打回"}：构造 `tianting_fu::验收回执`、落盘到 `.上下文/状态/验收.jsonl`
  - 入参 `结论` 非法：返回 `"结论需为 通过|打回，当前：{结论}"` 字串、不落盘
  - 入队失败：返回 `"入队失败：{错误}"` 字串

### 1.2 辅助入口 — `mingling_fu::状态目录` / `mingling_fu::打开存储` / `mingling_fu::工作区根` / `mingling_fu::读模型配置`

- 文件：`乾坤/呈现-域/命令操作-府/命令-解析-殿/命令-入口-阁/兜底-入口-园/入口执行.rs`
- 路径：模块桥接 `入口执行` 暴露在 `mingling_fu` 库根
- 签名：
  - `pub fn 工作区根() -> std::path::PathBuf` — 读 `WORLD_WORKSPACE_ROOT` 环境变量，缺省回退到 `current_dir()`
  - `pub fn 状态目录() -> std::path::PathBuf` — `{工作区根}/.上下文/状态`
  - `pub fn 打开存储() -> shihai_fu::模型存储` — 打开 `{工作区根}/.上下文/格位` 模型存储
  - `pub fn 读模型配置() -> moxing_fu::模型配置` — 读 `.env` 文件后转 `moxing_fu::模型配置`
- 可见性：`pub fn`（库根导出符号）

## 2. 意图 / 裁决类型（冻结快照，复用 `tianting_fu`）

### 2.1 `tianting_fu::验收结论`（enum）

- 变体：
  - `通过`
  - `打回`
- 用途：`裁决验收` 仅接受字面 "通过" / "打回" 两值映射到本 enum；非法字面落 warn 日志并返回错误回执字串。

### 2.2 `tianting_fu::验收回执`（struct）

字段（位置、类型）：

| 字段       | 类型                | 备注                              |
|------------|---------------------|-----------------------------------|
| `要求id`   | `String`            | 必填；测试断言必含                  |
| `结论`     | `tianting_fu::验收结论` | 必填；取值仅 `通过` / `打回`       |
| `验收意见` | `Option<String>`    | 透传意见；`None` 时 Some("")       |
| `产物`     | `Vec<_>`            | 裁决时为空 Vec                     |
| `耗时秒`   | `f64`               | 裁决时为 `0.0`                     |

## 3. Err 变体全集（机械可判定边界）

`裁决验收` 是 `String` 返回（无 `Result` 包装），其错误变体以回执字串前缀枚举：

| 前缀正则                            | 含义                          | 落盘行为 |
|-------------------------------------|-------------------------------|----------|
| `^验收已裁决`                       | 成功入队                      | 写入     |
| `^结论需为 通过\|打回，当前：`      | 结论字面非法                  | 不写     |
| `^入队失败：`                       | `落盘队列::入队` 返回 `Err`   | 不写     |

测试侧须以 `回执.contains(...)` 命中以上前缀；不得引入新的 Err 通道（panic/unwrap 等另算异常兼容路径）。

## 4. 序列化格式（冻结）

### 4.1 serde 表示

- `tianting_fu::验收回执` 的序列化由 `tianting_fu` 内部 serde derive 决定（已在依赖列表 `serde + serde_json`）。
- 本园不直接做序列化，仅将结构体交给 `tianting_fu::落盘队列::<验收回执>::打开(...)`，由该队列完成 JSON 序列化追加到 `.jsonl`。
- 测试侧不得假设字段顺序；断言只比对"已落盘"+"内容含要求id"。

### 4.2 字段命名策略

- 字段名与 Rust 字段同名（蛇形中文标识），无 rename attr；序列化字段为字段名原值。

### 4.3 版本字段

- 当前 `验收回执` 未含 schema 版本字段；向后兼容由 `tianting_fu` 升级时补，本测试不主动加版本号。

## 5. 持久化事务边界（冻结）

- 写入通道：`tianting_fu::落盘队列::<验收回执>::打开(状态目录().join("验收.jsonl")).入队(&回执)`
- 事务边界由 `落盘队列` 内部保证；本园视为原子追加。
- 失败回滚语义：入队 `Err` 时回执不返回 `"验收已裁决"` 前缀；测试侧以"前缀不存在 + 落盘文件未生成 / 未追加"双判。
- 幂等语义：相同要求id 连续两次入队均成功（队列追加语义，非 upsert）。

## 6. trait 抽象 / mock 可行性判定

- `裁决验收` 未依赖任何 trait 抽象，签名是纯 `&str` → `String` 字串接口。
- 结论：`mock` 不可行（无 trait 注入点）；测试侧仅做端到端（真实落盘 + 真实队列）断言，不构造 mock 对象。

## 7. 全局可变状态 / 静态变量 / 线程局部存储

- 探查结论（基于批量审验.rs 与入口执行.rs 的完整定义）：
  - 全局可变状态：无（`mut static` / `lazy_static!` / `OnceCell` 等均未出现）
  - 静态变量：无
  - 线程局部存储：无（无 `thread_local!` 宏调用）
  - 环境变量：仅 `WORLD_WORKSPACE_ROOT`（作为配置入口，非状态）
- 结论：测试侧可直接并发调用 `裁决验收`，各线程以 UUID 前缀状态目录隔离即可，不存在共享污染。

## 8. 并发隔离通道（冻结方案）

- 每线程独立子目录：`{隔离根}/{uuid}/{要求id}`
- 隔离根：`std::env::temp_dir().join("裁决验收隔离").join(唯一)`
- 环境变量互斥：通过 RAII 守卫串行化 `WORLD_WORKSPACE_ROOT` 写入，保证不跨线程污染
- teardown：测试结束 `remove_dir_all(&隔离根)` 清理

## 9. 可机器校验不变量（grep 守卫）

| 不变量 ID    | grep 表达式                                                                  | 命中位置                          |
|--------------|-------------------------------------------------------------------------------|-----------------------------------|
| INV-NO-LOCAL | `grep -nE 'pub (enum|struct|fn) (裁决|验收回执|验收结论)' 验收-裁决-验证-园` | 命中 = 0；除 `裁决验收` 外不得本地重定义 |
| INV-NO-CRUD  | `git status --porcelain 验收-裁决-验证-园/tests` 仅允许新增 `*.rs`            | tests 目录下禁止 fixtures/数据文件    |
| INV-LF       | `file 验收-裁决-验证-园/**/*.rs` 全部 `ASCII text, with LF`                  | 禁止 CRLF 落盘                        |

> 不变量 INV-NO-LOCAL 已通过现有测试 `裁决验收_引用冻结快照而非本地重定义` 在编译期兜底（必须引用 `mingling_fu::裁决验收` 句柄）；CI 端 grep 作为第二道闸门。
