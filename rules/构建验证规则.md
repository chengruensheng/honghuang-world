# 构建与验证规则

## 一、验证门槛
1. 每次改动后必须 `cargo build`（零警告）+ `cargo test`（全绿）方可交付。
2. 关键路径（装配、闭环）用 `cargo run -p hm-bootstrap` 验证启动自检。

## 二、Windows 编译异常处置
1. rustc 增量编译缓存损坏会致 ICE（`no entry found for key` / 拒绝访问）。
2. 处置：`cargo clean`，或 `$env:CARGO_INCREMENTAL=0; cargo build`。

## 三、PowerShell 输出误报
1. PowerShell 下 `cargo ... 2>&1` 的 `NativeCommandError` 属误报。
2. 以退出码与 `test result` 为准，不以该红字判断失败。
