# 命名规则与结构约束

## 一、命名格式（各层后缀，均为文件夹）
- 域：`4字-域`
- 府：`4字-府`（含 Cargo.toml）
- 殿：`2字-2字-殿`
- 阁：`2字-2字-阁`
- 园：`名字-类型-园`（三段式：名字 + 类型 + 园；**园是文件夹**，代码文件放在园内）

## 二、园的"类型"词
园的三段式中间段是"类型"词，表示园内内容的类别，如：`数据`、`配置`、`模块`、`接口` 等。
- 示例：`错误-数据-园`、`默认-配置-园`、`日志-模块-园`

## 三、命名唯一性（严禁同名）
1. 同级节点语义词不重复（如同一域下两府不得同名）。
2. 下级节点语义词不得与其直接上级相同，即 域≠府、府≠殿、殿≠阁、阁≠园。
   - 例：禁止 `启动装配-域` 与 `启动装配-殿` 并存。
3. 判定以"去掉后缀的语义词"为准（如"启动装配"；园以"名字-类型"整体判定）。

## 四、域数量上限
1. 一个根（维度）下的域 ≤ 3（硬约束，超限必须合并而非新增）。
2. 域下府数不限（府是独立编译单元，可多）。
3. 府下殿 ≤ 6、殿下阁 ≤ 4（沿用既有硬约束）。

## 五、禁止英文命名
非强制情况下严禁 `src` 等英文文件命名（代码落园，无 `src` 目录）。

## 六、crate 命名
crate 包名 = 根拼音缩写 + 英文语义：鸿蒙=hm、太初=tc、量劫=lj、乾坤=qk、道韵=dy、混沌=hd、证道=zd。
