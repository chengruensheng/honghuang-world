# 格位（.传承 侧视图）

## 定位
本目录是 `.传承/` 规范下的「格位」子目录，承载角色格位定义及其演变历史。

## 文件
| 文件 | 作用 | 唯一源 |
|------|------|--------|
| `36格位.json` | 格位定义本体（30 实证格位 + 6 扩展位） | 本体 |
| `演变/演变记录.md` | 格位定义变更时间线 | 指向 `36格位.json` |

## 边界
- 演变记录不复制格位内容，唯一源为 `36格位.json`，避免双份漂移。
