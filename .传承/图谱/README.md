# 图谱（.传承 侧视图）

## 定位
本目录是 `.传承/` 规范下的「图谱」子目录，承载架构图、数据流、调用链、知识图谱四类认知产物。

## 子目录
| 子目录 | 内容 | 状态 |
|--------|------|------|
| `架构图/` | 架构全览 | 占位（本项目架构图已弃） |
| `数据流/` | 数据流向 | 占位（待建） |
| `调用链/` | 调用关系 | 占位（待建） |
| `知识图谱/` | 坐标层 + 符号层 | 已建（两阶段产物） |

## 知识图谱两阶段
| 阶段 | 内容 | 项目特化定义 | 数据本体 | 摘要 |
|------|------|-------------|---------|------|
| 1 坐标层 | 路径 → 多层语义坐标 | `坐标定义.json` | `坐标索引.json` | `坐标索引.md` |
| 2 符号层 | 源码 → 符号与事实边 | `解析定义.json` | `符号索引.json` | `符号索引.md` |

> 引擎均语言无关，仅消费项目特化定义文件，换定义即可服务其他项目。
> - 坐标层引擎：`.传承/门禁/生成坐标索引.ps1`
> - 符号层引擎：`hm-symext`（见 `.传承/设计/落地设计/语言解析插件-落地设计.md`）

## 边界
- 知识图谱产物为「数据本体 `.json` + 摘要 `.md`」双重形式，本目录只维护索引，不复制内容。
