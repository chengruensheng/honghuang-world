# 规则（.传承 侧视图）

## 定位
本目录是 `.传承/` 规范下的「规则」子目录，是 IDE 接入项目时读取规则的**认知接口层**。

## 与 `rules/` 的关系
- **唯一源**：本项目规则的唯一权威源仍是根目录 `rules/`（12 个 `.md`），以 `rules/` 为唯一权威源。
- **本目录**：`.传承/规则/` 是 `.传承/` 侧的同构视图/规范占位，不复制规则内容。
- **不做 junction**：本目录与 `rules/` 之间**不建立目录联接（junction）**，以避免 Windows 重解析点（ReparsePoint）在删除子目录时穿透到源目录、污染 `rules/` 真实内容。

## 三个子目录（规范层划分）
| 子目录 | 含义 | 进 git |
|--------|------|--------|
| `大道规则/` | 不可改（项目宪法） | 是 |
| `天道规则/` | 可议（项目法律） | 是 |
| `临时规则/` | 任务级，终态清除 | 否 |

## 当前状态
- 本项目规则暂未按「大道/天道/临时」三级物理拆分，仍统一存放于根 `rules/`。
- 未来如需三级分层，可将 `rules/` 中带 frontmatter「层级: 大道」的文档映射到 `大道规则/`，以此类推。
