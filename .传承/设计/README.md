# 设计（.传承 侧视图）

## 定位
本目录是 `.传承/` 规范下的「设计」子目录，承载落地设计、设计原则、已定契约三类文档的认知索引。

## 与 `传承殿/` 的映射（逐步迁移 · 文件原位）

> 规范约定「老文件逐步过渡、不做全量物理迁移」，故本目录当前以**索引映射**方式关联 `传承殿/`，文件不物理移动，避免破坏既有引用——尤其 `传承殿/已定契约-域/已定契约.md` 被 8 个落地设计文档作为「上游契约」引用，物理移动将致引用断裂。

| `.传承/设计/` 子目录 | 对应物理位置 | 文件 |
|----------------------|-------------|------|
| `已定契约/` | `传承殿/已定契约-域/` | `已定契约.md`、`对外接口契约.md`（2 个） |
| `落地设计/` | **本目录新建** + `传承殿/落地设计-域/`（存量） | 新建：`语言解析插件-落地设计.md`；存量 11 个落地设计/引擎设计 + `缺陷修复规划.md`（验收报告归治理，见下） |
| `设计原则/` | `传承殿/设计原则-域/` | `核心设计原则.md`、`完整架构蓝图.md`、`洪荒本体论.md`、`三态认知底座.md`、`AI_Agent前沿调查.md`、`设计参考-府/`（6 个） |

## 过渡规则
- 未来**新建**设计文档，直接落 `.传承/设计/` 对应子目录，不再放 `传承殿/`。
- 老文档保留原位，逐步过渡；物理迁移前须先同步更新所有引用（见 `rules/.传承结构规范.md` 第十一节）。
- 验收报告虽物理位于 `传承殿/落地设计-域/`，逻辑上归 `.传承/治理/验收报告/`（见 `.传承/治理/README.md`）。
