# 代码文档生成（知识图谱第 3 阶段）

> **定位**：定义「知识图谱」第 3 阶段（叙述层）——把第 2 阶段产出的符号与边，翻译成**可溯源、可校验**的人读文档。事实只有一个来源（`符号索引.json`），文档只是它的呈现；文档里出现的每个符号引用都能回到事实图上找到出处。
> **不解决什么**：不做符号提取（第 2 阶段已做）、不做坐标归一（第 1 阶段已做）、不做诊断规则（第 4 阶段）、不校验 LLM 输出的文风与结论质量（只校验事实性）。

**关联**：`.传承/图谱/知识图谱/符号索引.json`（唯一事实源）、`.传承/设计/落地设计/语言解析插件-落地设计.md`（上游：符号层）、`.传承/图谱/README.md`（图谱侧视图）、`rules/命名规则.md`、`rules/可插拔规则.md`

## 一、诉求与结论

### 诉求

符号层回答了"谁定义了什么、谁引用了谁"，但没回答"这块代码在干什么"。473 个源文件靠人逐个读不现实；让 AI 每次从零读一遍，成本高且结论不稳定。

需要一层**叙述**：把事实图翻译成人读文档。但这层有个致命风险——**叙述会脱离事实**。LLM 会顺手编出一个不存在的函数名、一个不存在的调用关系；读者无从分辨哪句是真的。**错误的文档比没有文档更糟**，因为它会被当真。

### 结论

新增独立府「代码文档」，消费 `符号索引.json`，产出每源文件一篇 Markdown + 索引页 + **校验报告**。

三个要点：

1. **事实唯一**：不自建解析器，只读符号索引。避免双事实源漂移。
2. **叙述可插拔**：叙述器是 trait，模板实现（确定性、离线）与模型实现（复用 `hm-content`）可替换。
3. **自带防幻觉**：叙述文本中的符号引用必须能在事实图中溯源，否则记为「疑似幻觉」并计入报告。

### 与外部原型的关系

原型（`F:\自动化生成文档`）是同一想法的独立验证：TS 实现，约 7 分钟生成 158 篇，含 LLM 叙述与防幻觉校验。它证明了两件事——这条路走得通；防幻觉必须内建。

但它是**另一个事实源**：自研 tree-sitter 解析产出自己的 `ir.json`。与本设计并存会形成双份真相，同一符号在两处不一致。

| 维度 | 原型 | 本设计 |
|---|---|---|
| 事实源 | 自研解析（`ir.json`） | 复用 `符号索引.json`（唯一） |
| 语言与集成 | TS，独立项目 | Rust，同仓，可被编排 |
| LLM 接入 | 自建（`DOCGEN_LLM_*`） | 复用 `hm-content`（`LLM池`） |
| 校验白名单 | 英文字段名 + 中文标识符豁免 | 中文标识符**重点校验**，且不硬编码任何语言关键字 |
| 结论 | 思路采纳 | 代码不搬 |

### 与 `项目认知-府`、`内容生成-府` 的边界

| 府 | 职责 | 与本设计的关系 |
|---|---|---|
| `项目认知-府` | 运行时世界态（内存、随进程生灭、`persistence.dir/` 状态、不入 git） | 不同生命周期。本设计产出**入 git**（源），供跨会话差分 |
| `内容生成-府` | 纯 LLM 接入（供应商池、绑定、故障转移） | 本设计**消费**它，不重复实现接入；它不知道文档的存在 |
| `符号解析-府` | 语言无关的事实提取（引擎 + 插件调度） | 本设计**消费**其产出，不反向依赖 |

## 三、设计决策

| # | 决策 | 选择 | 理由 |
|---|---|---|---|
| 1 | 事实来源 | 只读 `符号索引.json` | 双事实源必漂移；符号索引已达编译级精度，无必要自建 |
| 2 | 叙述层形态 | `Arc<dyn 叙述器>`，模板 / 模型两实现 | `rules/可插拔规则.md` §一；模板实现是**真实实现变体**（非 mock），可离线验收 |
| 3 | 文档粒度 | 每源文件一篇 | 与 `符号.文件` 字段天然对齐，路径即溯源坐标 |
| 4 | 防幻觉策略 | 叙述中的符号引用必须可溯源 | 文档错了比没有更糟 |
| 5 | 产出落位 | `.传承/图谱/知识图谱/代码文档/` | 知识图谱第 3 阶段；**源**（入 git） |
| 6 | 府内语言无关 | 不出现任何语言名 | 与引擎同构；校验白名单不硬编码语言关键字，改用事实集动态取词 |
| 7 | 生成策略 | 每次全量重生成，不做增量 | 模板叙述秒级；增量需判输入变更，一旦漏项即产生**静默陈旧** |
| 8 | 失败处理 | 单篇失败不中断整批 | 沿用上游「任何单点失败不得使整张图谱失败」 |
| 9 | 校验自检 | 内建自检：注入虚构符号名，断言校验能抓到 | 没有自检的校验器，无法证明它真的在工作 |

## 四、契约定义

### 4.1 文档事实（渲染与校验的共同输入）

```rust
/// 一个源文件在事实图上的投影
pub struct 文档事实 {
    pub 文件: String,                       // 仓库相对路径
    pub 坐标: BTreeMap<String, String>,     // 根/域/府/殿/阁/园
    pub 来源语言: String,
    pub 定义: Vec<hm_symext::符号>,          // 本文件定义的符号
    pub 出边: Vec<hm_symext::边>,            // 本文件发出的边
    pub 入边: Vec<hm_symext::边>,            // 指向本文件符号的边
    pub 悬空: Vec<hm_symext::悬空>,          // 本文件内的悬空引用
}
```

`符号` / `边` / `悬空` 直接复用 `hm-symext` 契约，**不另立同义类型**。

### 4.2 叙述器契约

```rust
/// 把事实投影成人读文本。实现须保证：只陈述事实中存在的内容。
pub trait 叙述器: Component {
    fn 叙述(&self, 事实: &文档事实) -> Result<String>;
}
```

| 实现 | 性质 | 用途 |
|---|---|---|
| `模板叙述器` | 确定性、离线、零成本 | 默认；作模型实现的**兜底**与对照组 |
| `模型叙述器` | 复用 `hm-content::内容生成器` | 生产；失败时逐篇降级到模板叙述器 |

失败降级是逐篇的：某篇模型调用失败，该篇用模板产出，其余不受影响。

模型叙述器的两处硬要求：

1. **清单同源**：提示词必须把「可引用名」清单（= `文档事实::可引用名()`，与校验器同一函数）原样交给模型。模型不知道哪个名字真实存在，不给清单就只能凭训练知识补全，那正是幻觉的来源。
2. **剥离思考块**：推理模型会把推理过程写进正文（如 MiniMax 的 `<think>…</think>`）。产出前必须剥离；闭标签缺失时按「思考未尽」丢弃其后内容——宁可少一段，不可把推理过程当正文。

后端选择由 CLI 决定：`--叙述 模板|模型`，默认模板。`--叙述 模型` 时凭据取自 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`（`LLM_FALLBACK_*` 三项齐全则作故障转移）；后端不可用则**整批**回落模板，并在报告的「叙述器」一行如实注明。

### 4.3 校验契约

```rust
pub enum 判定 {
    通过,
    疑似幻觉 { 引用: String, 出处: Vec<String> },
}

pub struct 校验结论 {
    pub 文件: String,
    pub 判定: 判定,
}
```

**校验规则**（语言无关）：

1. 只校验**符号引用形态**的 token——反引号包裹的标识符，或含 `::` 的路径。
2. 可采信的出处集合 = 本文件定义的符号名 ∪ 出入边的两端符号名 ∪ 边词表 ∪ 符号种类词。
3. 不在集合内 → 记「疑似幻觉」。**宁可漏报，不可误报**：规则的词不参与校验，普通叙述文字不参与校验。

## 五、职责链与降级

### 5.1 职责链

```text
1. 读 符号索引.json              → 事实源
2. 按 符号.文件 分组             → 每文件一份 文档事实（并入边、悬空）
3. 逐文件叙述                    → 叙述器（模板 / 模型）
4. 逐文件校验                    → 比对叙述文本与事实集
5. 渲染 Markdown + 索引页        → 每文件一篇 + index.md
6. 汇总校验报告 + 自检           → 校验报告.md
```

### 5.2 降级矩阵

| 情况 | 行为 |
|---|---|
| 某文件无符号 | 仍生成一篇（只陈述"该文件未定义符号"），不留空洞 |
| 单篇叙述失败 | 降级到模板叙述器；模板也失败则记入报告并跳过该篇 |
| 模型后端不可用 | 整批降级到模板叙述器，报告中注明 |
| 事实源缺失 | 明确报错退出（不产出空文档集，避免误导） |
| 校验发现疑似幻觉 | **不删改文档**，只在报告中列出——判断权交给人 |

**原则**：文档可以少，不可以错而不报。

## 八、验收基线

1. **事实唯一**：府内不存在任何独立的源码解析逻辑——所有符号与边均来自 `符号索引.json`。
2. **语言无关**：对府源码 grep 语言名词（rust / javascript / python 等），零命中。
3. **可溯源**：每篇文档的文件名与首个标题均为源文件相对路径；文档内不出现该路径之外的、事实集中不存在的符号。
4. **防幻觉有效**：自检注入虚构符号名后，校验器必须报出该条目。
5. **可复现**：同一份 `符号索引.json` 连续两次生成，产出逐字节一致（模板叙述器前提下）。
