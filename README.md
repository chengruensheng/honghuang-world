# 洪荒·世界

> 面向架构、AI 主刀 —— AI 原生的面向架构语言与开发平台。
> 全中文「九根六层」架构，AI 编写、人写律与骨架；架构即契约，契约即约束（律可机器校验）。

## 一键启动（开箱即用）

```powershell
# 方式 A：后端 + 浏览器（最稳，人人可用）
./启动.ps1

# 方式 B：桌面壳（内嵌 WebView2 窗口，后端/前端随壳启动）
./启动.ps1 -Desktop
```

- 启动后浏览器打开 **http://localhost:8321** 即可看到「世界入口」。
- 首次运行会自动 `cargo build`（稍慢），后续增量极快。

### 为什么默认用浏览器/桌面壳，而不是 IDE 内置预览？

本项目前端使用 **ES Module（`type="module"`）**。多数 IDE 内置预览/轻量 webview **不执行 module**，会显示白屏——这是引擎限制，不是代码问题。
- 解决：用**真浏览器**访问 `localhost:8321`，或使用**桌面壳**（`hm-desktop` 基于 WebView2，原生支持 module）。

## LLM 接入

首次使用需配置大模型（对话/看板驱动依赖 LLM）：
1. 界面右下角点「**接入供应商**」，选内置模板（DeepSeek / 智谱 GLM / 通义 Qwen / Kimi / MiniMax / 火山方舟 / OpenAI / OpenRouter / Ollama）或自定义；
2. 填官网 + API Key（推荐写 `env:变量名`，密钥不入库）→ 获取可用模型 → 接入并选择；
3. 或直接编辑 `default.toml` 的 `[llm]` 段（示例见文件注释）。

## 常用操作

- **发任务**：在「对话视图」描述需求 → 触发「发布 → 五层驱动」自动开发，过程实时滚动且**可回放**；
- **看板**：查看任务/迭代/进度；
- **认知图谱 / 格位**：查看项目认知三态（提炼/检索/压缩/纠错）；
- **历史会话回放**：对话视图左侧「历史会话」，点任一条回放全程过程（数据落盘 `persistence.dir/驱动会话`）。
