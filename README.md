# 洪荒·世界

> 面向架构、AI 主刀 —— AI 原生的面向架构语言与开发平台。
> 全中文「九根六层」架构，AI 编写、人写律与骨架；架构即契约，契约即约束（律可机器校验）。

**本项目为纯后端**：不含任何前端代码。数据服务以 HTTP + SSE 对外提供 API，
对外呈现面（CORS / 静态托管 / SSE 并发上限）由独立配置文件 **`对外契约.toml`** 声明，
接入或移除客户端只需改该配置，无需改动后端代码。

## 一键启动

```powershell
./启动.ps1
```

- 后端启动后数据服务监听 **http://127.0.0.1:8321**（纯 API）。
- 首次运行会自动 `cargo build`（稍慢），后续增量极快。

## 对外契约（前后端零耦合）

后端与客户端之间只通过「契约」交互，分两类：

| 类型 | 载体 | 说明 |
|---|---|---|
| 呈现参数 | `对外契约.toml`（工作目录） | CORS 来源白名单、静态托管目录、SSE 并发上限；空值 = 关闭对应能力 |
| 交互协议 | Rust 契约 crate（`鸿蒙/基础契约-域/交互协议-府` 等） | 事件词表 / 数据模型，单一真相源，不外置 |

`对外契约.toml` 缺省时使用编译期嵌入的默认值，可零配置直接跑纯 API。

## LLM 接入

对话 / 看板驱动依赖大模型，在 `default.toml` 的 `[llm]` 段配置：
- 供应商、模型、API Key（密钥推荐写 `env:变量名`，明文不入库）。

## 目录速览（九根）

| 根 | 作用 |
|---|---|
| 鸿蒙 | 基础契约 + 基础能力 + 系统装配（后端引擎本体） |
| 乾坤 | 记忆管理（记忆核心） |
| 太初 | 任务管理 |
| 量劫 | 迭代管理 |
| 道韵 | 规则管理（律） |
| 混沌 | 事件管理 |
| 证道 | 验证 / 测试 |
| 传承殿 | 契约 / 文档 / 设计 |

六层结构：根 → 域 → 府（独立编译单元）→ 殿 → 阁 → 园。

## 技术栈

Rust（axum，Cargo workspace），零前端构建依赖。
